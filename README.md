# Лабораторная работа №1

## Домашняя страница

Простой одностраничный сайт, созданный с использованием HTML и CSS.

На сайте представлены информация обо мне, мои увлечения, расписание и контактная информация.

## Используемые технологии

- HTML5
- CSS3
- Google Fonts (Roboto)

## Содержание сайта

- Шапка с навигационным меню
- Раздел «Обо мне»
- Раздел с увлечениями
- Таблица с расписанием
- Изображение
- Футер с контактной информацией
